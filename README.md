| 04 | **AI Amplification** | Systems that scale everything above without scaling headcount |

## How we work

1. **Diagnose** — map where visibility is actually breaking down before proposing anything.
2. **Build** — design and ship the system itself — not a recommendations document.
3. **Compound** — stay in the system as it runs, refining instead of resetting every quarter.
