# Build

Purpose: design and ship the exposure system itself — not a recommendations document.

## What gets built

### 01 — Positioning

- Differentiated position: who you are, why it matters, why a competitor can't say the same thing
- Messaging that works in every channel (web, social, cold outreach, sales, referral)

### 02 — Content

- Content built to be found (search / answer engines)
- Content built to be redistributed (not just posted once)
- A system, not a one-off burst

### 03 — Distribution

- Channels where the right people already are
- Distribution wired into client operations (booking flow, CRM, sales process)
- Local SEO and answer-engine visibility where relevant

### 04 — AI Amplification

- Systems that scale content, personalization, and distribution
- Scale without scaling headcount

## Infrastructure to ship

- Website / landing infrastructure
- Booking / conversion flow
- CRM and tracking where relevant
- Publishing and distribution setup
- Reporting / measurement loop

## Definition of done

- The system is live
- It is wired into how the client operates
- It ships results we can show, not a document to file away
