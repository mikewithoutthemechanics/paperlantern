# Build Playbook

Purpose: ship the exposure system — infrastructure, not a recommendations document.

**Duration:** ~4–8 weeks typical.

---

## Step 1 — Kickoff

- Confirm scope from the Diagnose map
- Agree on the build plan (what ships, by when)
- Set up access to all systems (domain, analytics, CRM, socials, booking)
- Set up a shared workspace + weekly check-in rhythm

## Step 2 — Lock positioning

- Define who you are, why it matters, and why a competitor can't say the same thing
- Test it against real customer language
- Write it once, use it everywhere (site, outreach, sales, LinkedIn)

## Step 3 — Build content engine

- Create the content pillars (based on customer questions and search intent)
- Build content that is:
  - **Findable** — answers the questions customers actually search
  - **Redistributable** — built to be shared, referenced, and repurposed
  - **Always on** — a pipeline, not a one-off explosion

## Step 4 — Wire distribution

- Identify channels where customers actually are
- Wire visibility into operations:
  - Local SEO → booking flow
  - LinkedIn → outreach/sales pipeline
  - Answer engines → content that converts at the moment of search
- Make it part of how the business runs, not a separate activity

## Step 5 — Ship infrastructure

- Website / landing pages
- Booking / conversion flow
- CRM + tracking (if not present)
- Publishing/distribution automation
- Measurement loop (what we'll report on)

## Step 6 — Launch

- Publish the system live
- Verify each piece works end-to-end
- Document what was shipped (for the case study)

## Step 7 — Handoff / continue

- If client continues to Compound: transition to operating rhythm
- If not: hand over with clear ownership and documentation

---

## Build definition of done

- [ ] Positioning locked and usable everywhere
- [ ] Content engine exists and is producing
- [ ] Distribution wired into operations
- [ ] Full infrastructure shipped and live
- [ ] Measurement loop in place
- [ ] Case-study log started
