# Compound Playbook

Purpose: run the exposure system month-to-month, refining instead of resetting.

**Duration:** ongoing / retainer.

**Goal:** visibility compounds. Every month builds on the last.

---

## Monthly rhythm

| Week | Work |
|------|------|
| Week 1 | Review last month's numbers, identify what moved, agree priorities |
| Week 2 | Run the system (content, distribution, amplification) |
| Week 3 | Run the system, course-correct from early signals |
| Week 4 | Measure, document, report |

---

## What we do every month

1. **Operate** — run the exposure system (content, distribution, amplification)
2. **Measure** — track outcomes, not vanity metrics
   - Leads / inquiries
   - Booked jobs / calls
   - Conversion rate
   - Response time
   - Visibility signals (rankings, mentions, redistributions)
3. **Refine** — adjust positioning, content, and distribution based on real data
4. **Scale** — use AI amplification to increase output without scaling headcount
5. **Report** — show the work, show the numbers

---

## Client responsibilities

- Access to operational systems (CRM, analytics, booking, accounts)
- Timely feedback on strategic direction
- A "ship things" culture, not a committee that approves decks

---

## Monthly report format

See `templates/monthly-report.md`.

Sections:
- Numbers vs last month
- What worked
- What changed (positioning/content/distribution)
- Where we're tuning next
- Proof worth logging for the case study

---

## Definition of done (per month)

- [ ] System ran
- [ ] Evidence captured
- [ ] Real improvements made
- [ ] Client saw outcomes, not just activities
- [ ] One piece of proof captured (quote, number, screenshot) for future case studies
