# Client Offboarding / Handover Checklist

How PaperLantern closes any engagement cleanly — so the client keeps the system working after we leave, and we keep usable proof.

---

## Finish line

- [ ] All in-scope deliverables shipped
- [ ] Final report delivered
- [ ] All outstanding invoices settled
- [ ] Internal case-study evidence log complete

---

## Handover to client

- [ ] All system assets documented (what was built, where, how it runs)
- [ ] Access transferred to client (accounts, domains, CMS, CRM, booking, socials)
- [ ] Client can run what they need to run without us
- [ ] Any ongoing manual steps documented clearly

---

## What we keep

- [ ] Case-study worthy facts (with client permission)
- [ ] Client quote (optional, permission-based)
- [ ] Screenshots / metrics for proof
- [ ] Handover summary exported to our files (anonymized if needed)

---

## Clear communication

- [ ] Final close-out call or message
- [ ] Confirm what's ending (access, reporting, support)
- [ ] Offer what's next (Compound retainer, one-off re-engagement, referral)

---

## Internal wrap-up

- [ ] Playbooks updated if anything changed
- [ ] Templates updated if something was missing
- [ ] Files organized / archived
- [ ] Referral relationship noted (if applicable)
