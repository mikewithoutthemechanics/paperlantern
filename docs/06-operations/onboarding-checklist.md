# Onboarding Checklist

Internal checklist to run before any client engagement (Diagnose, Build, or Compound) kicks off.

---

## Before kickoff

### Contract & commercial
- [ ] Engagement agreement signed (see `templates/engagement-agreement.md`)
- [ ] Invoice / deposit process agreed
- [ ] Scope confirmed (Diagnose / Build / Compound)
- [ ] Start date + weekly rhythm agreed

### Systems & access
- [ ] Website / CMS access
- [ ] Analytics
- [ ] CRM
- [ ] Booking system
- [ ] Social media accounts
- [ ] Any other tools relevant to the engagement

### Internal prep
- [ ] Kickoff notes template started (see `templates/kickoff-notes.md`)
- [ ] Shared workspace / folder created
- [ ] Case-study evidence log started
- [ ] Client contact + decision-maker confirmed
- [ ] Weekly check-in time booked

---

## At kickoff (first call)

- [ ] Confirm what we're shipping (map, not deck)
- [ ] Confirm client responsibilities
- [ ] Confirm access is working
- [ ] Confirm definition of success (their words)
- [ ] Agree on how we report (outcomes, not vanity metrics)
- [ ] Set communication expectations (response-time standards)

---

## After kickoff (within first week)

- [ ] First deliverable underway
- [ ] Client has seen where work starts
- [ ] Access list final
- [ ] Next check-in booked
- [ ] If applicable: Exposure Audit map or build plan direction confirmed
