# Build Kickoff Checklist

Detailed checklist for starting a Build engagement. Use with `onboarding-checklist.md` (general) — this one is Build-specific.

---

## Pre-kickoff

- [ ] Engagement agreement signed (Build + optional Compound)
- [ ] Deposit / first payment received
- [ ] Access to all systems confirmed (website, CMS, booking, CRM, analytics, socials)
- [ ] Proposal or scope confirmed

---

## Kickoff call (30–45 min)

- [ ] Confirm what's being built (not a deck)
- [ ] Review Diagnose map priorities
- [ ] Lock definition of success (their words)
- [ ] Confirm Build timeline + milestones
- [ ] Confirm weekly check-in day/time
- [ ] Set expectation: we ship, they approve, no decks

---

## Week 1

- [ ] Position locking started
- [ ] Customer/competitor research underway
- [ ] Content pillars drafted
- [ ] Access verified working
- [ ] First weekly check-in done

---

## Weeks 2–4

- [ ] Positioning finalized and usable everywhere
- [ ] Content engine producing (findable + redistributable)
- [ ] Distribution channels selected
- [ ] Wire visibility into operations (booking, CRM, response flow)
- [ ] Infrastructure build underway (site, booking, landing, tracking)

---

## Final weeks

- [ ] End-to-end flow tested (find → visit → enquire → response → book)
- [ ] Case-study evidence log started
- [ ] Measurement loop live (what we'll report)
- [ ] Final handoff / Compound transition (if applicable)

---

## Definition of done (Build)

- [ ] Positioning locked
- [ ] Content engine exists and producing
- [ ] Distribution wired into operations
- [ ] Full infrastructure shipped and live
- [ ] Measurement loop in place
- [ ] Case-study scoped
- [ ] Client can operate it (or we operate it in Compound)
