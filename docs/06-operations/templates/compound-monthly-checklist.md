# Compound Monthly Checklist

What happens each month on a Compound retainer. Use with the Compound playbook.

---

## Month-begin

- [ ] Pull last month's numbers (leads, booked, conversion, visibility)
- [ ] Draft monthly report (numbers + narrative + next focus)
- [ ] Flag anything case-study-worthy
- [ ] Notify client of report / deliver report

## Mid-month

- [ ] Run the system (content, distribution, amplification)
- [ ] Course-correct from early signals
- [ ] Weekly check-in sent/received
- [ ] Client items actioned (approvals, feedback)

## Month-end

- [ ] Final numbers for month logged
- [ ] Proof captured (screenshot, quote, number)
- [ ] Next month's focus defined
- [ ] Client report sent
- [ ] Invoice issued (if not automated)

---

## Every month, don't forget

- [ ] Did we actually move something client-cared-about? (outcome, not activity)
- [ ] Did we show the work?
- [ ] Did we ask for feedback (check-in or survey)?

## If month went great

- [ ] Ask for permission to use as case study (specific ask with numbers)
- [ ] Thank client, consider referral ask

## If month was quiet

- [ ] Be honest in report — no spin
- [ ] Course-correct plan for next month
- [ ] Watch for fit issues (client may not need Compound, or we're not delivering value)

---

## Kill criteria

If 2+ months show no measurable outcome and no clear path to one, have the honest conversation: is Compound right for this client? Sometimes the best move is ending it cleanly.
