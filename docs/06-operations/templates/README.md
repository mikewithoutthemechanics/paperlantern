# Templates

Reusable formats for PaperLantern work.

## Client-facing

| Template | Used for |
|---|---|
| `exposure-audit-intake.md` | Questionnaire sent before a Diagnose call |
| `visibility-breakdown-map.md` | The Diagnose deliverable — a map, not a deck |
| `client-welcome.md` | Onboarding one-pager for new clients |
| `client-onboarding-survey.md` | Operating context survey before kickoff |
| `proposal.md` | Scoped Build/Compound proposal after Diagnose |
| `quote-estimate.md` | Lighter quote for smaller scope |
| `weekly-checkin.md` | Weekly check-in format for Build/Compound |
| `monthly-report.md` | Client monthly reporting (see automations/client-reporting.md) |
| `lifecycle-survey.md` | Exit survey + testimonial/quote request |
| `faq-onepager.md` | Shareable "what's an exposure system?" one-pager |
| `case-study-client-facing.md` | Case study for public sharing |
| `diagnose-call-script.md` | 10-min qualifier + paid audit call script |
| `kickoff-agenda.md` | Client kickoff call agenda |
| `referral-program.md` | Referral ask + incentive flow |

## Full template flow by engagement stage

| Stage | Template |
|---|---|
| Lead | outreach → qualifier script → expose-audit intake → diagnose-call-script |
| Audit | visibility-breakdown-map |
| Proposal | proposal / quote-estimate |
| Kickoff | client-welcome, client-onboarding-survey, kickoff-agenda, kickoff-notes |
| Build | build-kickoff-checklist, weekly-checkin |
| Compound | compound-monthly-checklist, weekly-checkin, monthly-report |
| Proof | case-study-draft, case-study-client-facing, lifecycle-survey, referral-program |
| Business review | goals-metrics, monthly-ops-review |
